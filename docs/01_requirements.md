## 1. 背景と目的

### 1.1 背景
名取さなさんは 2026/11/20 の YouTube 生配信「さなちゃんねるトコトコおでかけビンゴを作ろう！」で、視聴者と一緒にビンゴを作った。翌 11/21、完成したビンゴカードの画像と「見た!!!」スタンプ画像が X で公開された。

- ハッシュタグ：#さなちゃんねるトコトコおでかけビンゴ
- ルール：見つけたらビンゴに丸をする。期限はない。ビンゴしたら「うれしい！」
- キャッチコピー：「おでかけをちょっとたのしく！ 人生のどこかで目指せおでかけマスター！」

### 1.2 現状の課題
| ID | 課題 |
|---|---|
| P-1 | 紙や画像のカードでは、どのマスを達成したか管理しにくい |
| P-2 | 外出中にスマホを片手で持ったまま印をつけたい |
| P-3 | 達成したマスの写真を記録として残したい |
| P-4 | ビンゴ数や達成状況を SNS でシェアしたい |

### 1.3 目的
おでかけ中にスマホだけでビンゴの達成管理・記録・シェアを完結できる、非公式ファンメイドの PWA を提供する。

## 2. 利用者と利用シーン

| 項目 | 内容 |
|---|---|
| 主な利用者 | 名取さなさんのファン（さなのばくたち） |
| 公開範囲 | 当面は URL を知っている人向けの実質的な限定公開。将来は一般公開を目指す |
| 主な端末 | スマートフォン（iOS Safari / Android Chrome）。PC でも表示は崩れないこと |
| 利用シーン | 散歩・展示イベントなどへの外出中。片手操作で、電波が弱い場所でも使う |

## 3. 対象ビンゴカード

5×5 マス。配置は公式カードと同じ並びで固定する。期限はない。

| 行＼列 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 1 | ソフトクリームオブジェ | 珍しい色や形のポスト | うんち | SENRO NO OWARI | 元気に咲いた花 |
| 2 | トマソン | パンダのスプリング遊具 | 何かの教室 | 萌えキャラ | 誤字 |
| 3 | キノコ | 動物型のカンバン | **ちょっとおしゃれして…出発!!**（FREE） | 光るイヌ | カカシ |
| 4 | 飛び出し坊や（とび太） | パブリックアート | ケツみたいな石 | ダジャレ医院 | もくもくえんとつ |
| 5 | コンクリよりも強い草 | うす or ほそ自販機 | 噴水 | アナザーカラーストア | 怖い経年劣化… |

- 補足説明を表示するマス：「トマソン」には、公式カードの注記に沿って「実用性がないのに何故か残されているドアやかいだんなどの事」と説明を付ける。
- 中央マスは FREE とし、最初から達成済みの状態で始める。

## 4. 機能要件

| ID | 機能 | 要件 | 対応課題 |
|---|---|---|---|
| FR-01 | カード表示 | 5×5 のカードを 1 画面に表示する。各マスには文字と絵文字でお題を出す（絵文字の割り当ては付録 A）。公式カードのイラストは使わない | P-1 |
| FR-02 | 達成状態の表示 | 達成したマスには「見た!!!」スタンプを重ねて表示する。写真があるマスは、その写真をサムネイルとして表示する | P-1, P-3 |
| FR-03 | マス操作シート | マスをタップすると画面下からシートが出る。シートでは「見た！（スタンプ）」「写真を撮る / 選ぶ」「メモ」「取り消し」ができる。ボタンは親指が届く画面下部にまとめる | P-2 |
| FR-04 | 達成記録 | 達成したマスごとに、達成日時（自動）、写真（任意・1 枚）、一言メモ（任意・最大 100 文字）を記録する。マスをタップすれば記録を見られる | P-3 |
| FR-05 | 写真の保存 | 撮影または選択した写真は、縮小し、EXIF（位置情報を含む）を取り除いてから端末内に保存する | P-3 |
| FR-06 | 取り消し | 達成済みのマスを未達成に戻せる。写真やメモも消える場合は確認ダイアログを出す。FREE マスは取り消せない | P-1 |
| FR-07 | ビンゴ判定 | 縦 5・横 5・斜め 2 の計 12 ラインを判定する。ビンゴ数と達成マス数（例：12/25）を常に表示する | P-1 |
| FR-08 | ビンゴ演出 | 新しくラインが揃ったら、そのラインを光らせて「うれしい！」を表示し、シェアボタンを出す | P-4 |
| FR-09 | 全マス達成演出 | 25 マスすべて達成したら「おでかけマスター」の特別演出を出す | P-4 |
| FR-10 | シェア画像（カード） | 印付きのカードに、ビンゴ数と達成数、ハッシュタグを入れた画像を生成する | P-4 |
| FR-11 | シェア画像（写真入り） | 達成したマスに自分の写真を並べたカード画像を生成する。写真がないマスはスタンプで表示する | P-4 |
| FR-12 | シェア実行 | 投稿文（ハッシュタグ付き）と画像を Web Share API で共有する。使えない環境では、画像の保存と X の投稿画面（intent URL）を開く方法に切り替える | P-4 |
| FR-13 | リセット | カードを最初の状態（FREE マスだけ達成）に戻す。二段階の確認を挟む | — |
| FR-14 | エクスポート | 全データ（達成状態・日時・メモ・写真）を zip ファイル 1 つに書き出す | — |
| FR-15 | インポート | エクスポートした zip を読み込み、データを置き換えて復元する。置き換える前に確認する | — |
| FR-16 | アプリ情報 | 非公式ファンメイドであること、出典、二次創作ガイドラインへのリンク、遊ぶ際の注意（「人の迷惑にならないよう」）を表示する | — |

### 4.1 シェア投稿文（初期案）
```
トコトコおでかけビンゴ 3ビンゴ！（12/25マス）
#さなちゃんねるトコトコおでかけビンゴ
```
※ アプリの URL を載せるかどうかは、限定公開の方針と合わせて基本設計で決める。

## 5. 非機能要件

| ID | 区分 | 要件 |
|---|---|---|
| NFR-01 | 形態 | PWA としてホーム画面に追加でき、全画面で起動できる |
| NFR-02 | オフライン | 2 回目以降の起動ではネットワークなしで全機能が動く（X 投稿画面を開く操作を除く） |
| NFR-03 | データ保存 | ログインもサーバーも使わない。データは端末内（IndexedDB）にだけ保存し、外部へ送らない |
| NFR-04 | 操作性 | 片手で操作できる。タップできる要素は 44×44pt 以上。主な操作ボタンは画面下半分に置く |
| NFR-05 | 対応環境 | iOS Safari 17 以降、Android Chrome の最新 2 バージョン。PC 版の Chrome / Safari / Firefox の最新版でも表示は崩れない |
| NFR-06 | 性能 | 初回表示は 4G 回線で 3 秒以内。マスをタップしてからシートが出るまで 100ms 以内 |
| NFR-07 | 容量 | 写真は長辺 1280px 程度・JPEG に縮小し、目安として 1 枚 300KB 以下に抑える |
| NFR-08 | プライバシー | 保存する写真・シェア画像・エクスポートには位置情報（EXIF）を含めない。アクセス解析は入れない |
| NFR-09 | アクセシビリティ | 各マスにスクリーンリーダー用のラベルを付ける（お題名と達成状態） |
| NFR-10 | 費用 | 運用費は 0 円（GitHub Pages を使う） |
| NFR-11 | 保守性 | お題データはコードと分けてデータファイルとして持つ |

## 6. 制約（権利・ガイドライン）

[名取さな 二次創作ガイドライン](https://natorisana.com/guideline/) に従う。

| ID | 制約 |
|---|---|
| C-01 | 非営利とする。広告・寄付の募集・有料機能など、収益化は一切しない |
| C-02 | 公式と誤解されないようにする。アプリ名に「非公式」を付け、アプリ内と README に非公式ファンメイドであることを明記する |
| C-03 | 公式のイラスト、ロゴ、配信のスクリーンショット、公式カードの画像は使わない |
| C-04 | 例外として、公式が「よろしければスタンプもどうぞ」として配布した「見た!!!」スタンプ画像は、印として同梱して使う（依頼者の判断） |
| C-05 | ⚠️ C-04 は、ガイドライン FAQ の「公式画像の利用は許可していない」とぶつかる可能性がある。一般公開に広げる前に再検討する。指摘があれば差し替えられるよう、オリジナルの印も用意しておく |
| C-06 | 公式への個別の問い合わせはしない。ガイドラインは「確認が必要な行為は許可されないものとみなす」方針のため |

## 7. 対象外（今回は作らない）

- ログイン・クラウド同期・複数端末でのリアルタイム同期
- 他のユーザーとのランキングや交流機能
- 複数のカード（2 周目）や、カードの自作・編集
- 位置情報や地図との連携
- 1 マスに複数枚の写真を付けること
- 多言語対応（日本語のみ）
- ネイティブアプリ（iOS / Android）としての配布

## 8. 前提と未決事項

| 区分 | 内容 |
|---|---|
| 前提 | 公式カードの内容は今後変わらない。変わった場合は、お題データの差し替えで対応する |
| 前提 | 公開先は公開リポジトリ uu4k/natori-osanpo と GitHub Pages。当面は広く告知しない |
| 未決 | アプリ名は仮称「トコトコおでかけビンゴ帳（非公式）」。正式な名前は基本設計までに決める |
| 未決 | シェア投稿文にアプリの URL を入れるかどうか（基本設計で決める） |
